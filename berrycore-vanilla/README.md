# BerryCore Hardware Storefront (Vanilla HTML / CSS / Tailwind / JS / GSAP)

Standalone implementation of the BerryCore single-board computer storefront built using only:
- **HTML5**
- **CSS3 & Tailwind CSS v4** (`@tailwindcss/vite`)
- **Vanilla JavaScript** (ES Modules, zero frameworks)
- **GSAP + ScrollTrigger** (`gsap`)
- **Vite** (`vite`)

## Run Locally

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```
